# Everything Incremental

Um jogo incremental experimental em HTML, CSS e JavaScript, com foco em evolução livre, sistemas modulares e formas criativas de gerar progresso.

## Ideia do projeto

O objetivo do projeto é criar um incremental aberto, sem temática fixa inicialmente, permitindo que novas mecânicas, recursos e sistemas sejam adicionados livremente ao longo do desenvolvimento.

O jogo começa com uma base simples de pontos e melhorias, mas pode evoluir para sistemas mais criativos, abstratos e inesperados.

## Tecnologias

- HTML
- CSS
- JavaScript

## Objetivos iniciais

- Criar uma base simples e organizada
- Implementar ganho de pontos
- Adicionar melhorias básicas
- Estruturar o projeto de forma modular
- Evoluir o jogo por etapas, conforme novas ideias surgirem
